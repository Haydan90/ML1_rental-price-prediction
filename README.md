# Предсказание стоимости аренды квартир

## О проекте

В этом проекте я работал с задачей предсказания стоимости аренды квартир. Основная цель — изучить данные, попробовать разные модели машинного обучения и сравнить результаты их работы.

В процессе я провёл анализ данных, посмотрел на распределения признаков, изучил выбросы и обучил несколько моделей регрессии.

## Данные

Датасет

Для работы использовался датасет объявлений об аренде квартир из соревнования [Two Sigma Connect: Rental Listing Inquiries на Kaggle](https://www.kaggle.com/competitions/two-sigma-connect-rental-listing-inquiries/data).

В проекте я использовал файлы `train.json` и `test.json`. Датасет не хранится в репозитории, поэтому для повторения экспериментов его нужно скачать по ссылке выше.

Обучающая выборка содержит 49 352 строки и 15 столбцов.

Основные признаки, с которыми я работал:

- `bedrooms` — количество спален;
- `bathrooms` — количество ванных комнат;
- `interest_level` — уровень интереса к объявлению;
- `price` — стоимость аренды, которую нужно предсказать.

## Что было сделано

### 1. Анализ данных

- Изучил структуру датасета и основные статистические показатели.
- Посмотрел на распределение стоимости аренды.
- Изучил корреляции между признаками.
- Построил графики и тепловые карты корреляций.
- Проверил данные на наличие выбросов.

### 2. Подготовка данных

- Выбрал признаки для обучения моделей.
- Попробовал обработку выбросов с помощью квантилей.
- Подготовил данные для обучения и проверки моделей.
- Использовал масштабирование признаков для линейной регрессии.

### 3. Обучение моделей

Я попробовал несколько подходов:

- **Модель со средним значением** — в качестве прогноза использовалась средняя стоимость аренды.
- **Модель с медианой** — прогноз строился на основе медианной стоимости.
- **Linear Regression** — линейная регрессия с полиномиальными признаками 10-й степени.
- **Decision Tree Regressor** — дерево решений для предсказания стоимости.

### 4. Сравнение результатов

Для оценки качества использовал две метрики:

- **MAE** — средняя абсолютная ошибка предсказания.
- **RMSE** — корень из среднеквадратичной ошибки, который сильнее реагирует на большие ошибки.

## Результаты

| Модель | MAE на тесте | RMSE на тесте |
|---|---:|---:|
| Среднее значение | 1135.62 | 1590.11 |
| Медиана | 1084.26 | 1635.38 |
| Linear Regression (полиномиальные признаки) | 1210.23 | 69275.04 |
| Decision Tree Regressor | **759.14** | **1080.83** |

Лучший результат показало дерево решений: MAE составила 759.14, а RMSE — 1080.83.

Полиномиальная линейная регрессия показала менее стабильный результат. У неё получилась сравнительно небольшая MAE, но очень высокая RMSE. Поэтому эту модель стоит дополнительно проверить на большие ошибки предсказания.

## Выводы

В ходе работы я изучил данные, попробовал разные способы их обработки и сравнил несколько моделей для решения задачи регрессии.

Дерево решений показало лучший результат среди рассмотренных моделей и заметно превзошло простые прогнозы по среднему и медиане.

Также я увидел, что добавление полиномиальных признаков само по себе не гарантирует улучшения качества модели.

В дальнейшем можно попробовать другие признаки, подобрать гиперпараметры и сравнить результат с Random Forest и градиентным бустингом.
